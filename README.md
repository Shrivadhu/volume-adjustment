🎧 Volume Guard – Prevent Sudden Loud Sounds
Monitors Active Window: Continuously checks which application window is currently in focus.

Detects App Switches: Identifies when you switch between apps (e.g., from a quiet video to Spotify).

Checks System Volume: Automatically detects if your current system volume exceeds a safe threshold (e.g., 70%).

Lowers Volume Automatically: If the volume is too high during an app switch, it reduces it to a safe decibel level (e.g., -30 dB).

Sends Notification: Alerts you with a desktop notification that the volume has been adjusted for safety.

Runs Silently in Background: Can be added to system startup or bundled as an .exe to always protect your ears from sudden loud sounds.
